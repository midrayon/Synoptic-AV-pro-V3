    • Présentation

    SynOptic AV Pro v3 est un outil de conception de synoptiques audiovisuels et streaming. Il permet de créer des schémas de signal flow réalistes : micros, consoles, enceintes, amplificateurs, caméras PTZ, encodeurs, régie streaming, etc.

    Points clés :

    • Fonctionne entièrement dans le navigateur, sans installation
    • Thème clair par défaut, thème sombre disponible
    • Optimisé desktop et smartphone
    • 128 équipements intégrés en base (dont 46 dédiés régie streaming)
    • Validation des connexions selon la réalité physique des connecteurs
    • Sauvegarde locale automatique (localStorage)

    Démarrage rapide

    Sur PC

  • Ouvrir index.html dans un navigateur (Chrome, Firefox, Edge, Safari)
  • La bibliothèque est visible à gauche
  • Glisser un équipement depuis la bibliothèque vers le canvas
  • Glisser depuis un port d'un équipement vers un port d'un autre pour les connecter
  • Sauvegarder via 💾 Preset

    • Sur smartphone

  • Ouvrir l'URL hébergée dans Safari (iOS) ou Chrome (Android)
  • La bibliothèque s'ouvre via 📚 Biblio. dans la barre du bas
  • Appuyer sur + à côté d'un équipement pour l'ajouter
  • Glisser depuis un port vers un autre port pour connecter
  • Pincer avec deux doigts pour zoomer/dézoomer

    Bibliothèque d'équipements

    Recherche

    • PC : Taper directement dans le champ de recherche (barre latérale gauche). La croix ✕ efface la recherche.
    • Smartphone : Appuyer sur 📚 Biblio. → champ de recherche en haut du panel. La croix ✕ efface.
    • Recherche floue : sm58, dante, di, k12, atem, ndi, etc.
    • La recherche filtre par nom, sous-titre et tags simultanément.

    Catégories

    Les équipements sont organisés en groupes :

    Sources : Micros dynamiques · Condensateurs · Micros ruban · Micros HF · Cravate · Col de cygne

    Traitement : Tables numériques · Tables analogiques · Processeurs/EQ · Interfaces audio

    Diffusion : Enceintes actives · Enceintes passives · Caissons de basse · Retours scène

    Amplification : Amplificateurs

    Interface : Boîtes DI

    Infrastructure : Stage Box · Accessoires

    Capture : Enregistreurs

    Instruments : Cordes · Claviers · Vents · Percussions

    Vidéo : Vidéo / Projection

    Régie Streaming : Caméras · Cartes de capture · Mélangeurs vidéo · Encodeurs streaming · Ordinateurs/Logiciels · Moniteurs régie · Réseau · Audio streaming · Tally/Intercom · Accessoires régie

    • PC : Cliquer sur l'icône d'une catégorie pour filtrer. Cliquer à nouveau pour désélectionner.
    • Smartphone : Même logique dans la barre horizontale de catégories en haut du panel bibliothèque.
    • La catégorie active est toujours visible avec sa couleur de fond.

    Favoris

    • Cliquer sur ★ à côté d'un équipement pour l'ajouter aux favoris.
    • Cliquer sur ★ [n] en haut de la bibliothèque pour afficher uniquement les favoris.
    • Les favoris sont persistants entre les sessions.

    Ajouter un équipement personnalisé

    • PC : Cliquer sur + Ajouter en haut de la bibliothèque.
    • Smartphone : ••• Plus → (non disponible en direct, utiliser la version PC).
    • Remplir : Nom, Catégorie, Sous-titre, Description, Prérequis, Tags, Phantom 48V.
    • L'équipement personnalisé apparaît dans la bibliothèque avec les autres.
    • ⚠ Les ports ne peuvent pas être configurés sur les équipements personnalisés (connexions non disponibles).

    Ajouter des éléments au canvas

    PC

  • Glisser-déposer : Cliquer et glisser un équipement depuis la bibliothèque vers le canvas. Il se place exactement là où vous le déposez (compensé selon le niveau de zoom).
  • Bouton + : Cliquer sur le bouton + bleu à droite de l'équipement → il s'ajoute au centre du canvas.

    • Smartphone

  • Bouton + : Appuyer sur + à droite de l'équipement dans la bibliothèque. Le panel se ferme automatiquement et l'équipement apparaît sur le canvas.
  • Le glisser-déposer depuis la bibliothèque n'est pas disponible sur mobile.

    • Déplacer un élément

    • PC : Cliquer et glisser le node (en dehors des ports).
    • Smartphone : Poser le doigt sur le node et glisser. Le déplacement démarre après un léger mouvement (seuil de 6px) pour distinguer tap et drag.

    Minimap

    La minimap (haut droite du canvas) affiche une vue d'ensemble de tous les nodes avec leur couleur de catégorie, et un rectangle bleu indiquant la zone visible actuelle.

    • Cliquer/tapper sur la minimap → fitAll() : ajuste le zoom pour voir tous les éléments.
    • Elle se met à jour en temps réel pendant le zoom, le pan et l'ajout d'éléments.

    Créer des connexions (signal flow)

    Principe

    Les connexions respectent la compatibilité physique des connecteurs AV :

    • XLR mâle ▶ → XLR femelle ◀ uniquement
    • Jack TS ▶ → Entrée Jack ◀ (DI, ampli, interface)
    • Jack TRS ▶ → Entrée Jack ◀ ou XLR femelle ◀
    • Speakon ampli ▶ → Speakon enceinte ◀
    • Dante ▶ → Dante ◀
    • AES50 ▶ → AES50 ◀
    • SDI ▶ → SDI ◀
    • NDI ▶ → NDI ◀ ou Ethernet ◀
    • USB ▶ → USB ◀
    • USB-C ▶ → USB-C ◀ ou USB ◀
    • HDMI ▶ → HDMI ◀
    • Ethernet ▶ → Ethernet ◀ ou NDI ◀
    • Tally ▶ → Tally ◀

    Une connexion incompatible est bloquée avec un message d'erreur explicite.

    Méthode : Glisser-déposer (recommandée, PC et smartphone)

  • Poser le doigt ou la souris sur un port (carré avec point coloré).
  • Glisser vers le port cible sur un autre équipement.
  • Les ports compatibles s'illuminent en vert pulsé pendant le glissé.
  • Le port le plus proche sous le doigt/curseur se met en surbrillance.
  • Relâcher au-dessus ou à proximité (72px sur mobile, 44px sur desktop) d'un port compatible → la connexion se crée.
  • Un fil coloré apparaît selon le type de câble.
    • Astuce smartphone : Pas besoin d'être précis au pixel. Le système détecte le port compatible le plus proche dans un rayon de 72px autour du doigt.

    Méthode : Deux taps (alternative smartphone)

  • Tapper brièvement sur un port (sans glisser) → bannière de connexion apparaît en haut.
  • Les ports compatibles s'illuminent en vert.
  • Tapper sur un port vert sur un autre équipement → connexion créée.
  • Appuyer sur ✕ dans la bannière ou tapper le fond vide pour annuler.

    • Annuler une connexion en cours

    • PC : Touche Échap ou cliquer sur le fond vide du canvas.
    • Smartphone : Bouton ✕ dans la bannière bleue en haut, ou tapper le fond vide.

    Supprimer une connexion

    • PC : Double-cliquer sur le fil. Au survol, une info-bulle apparaît avec le type de câble et le rappel "2×clic".
    • Smartphone : Appui long (600ms) sur le fil → boîte de confirmation.

    Supprimer des éléments

    Supprimer un node

    • PC : Cliquer sur le ✕ en haut à droite du node, ou sélectionner puis appuyer sur Suppr ou Retour arrière.
    • Smartphone : Appuyer sur le ✕ en haut à droite du node.
    • ⚠ La suppression d'un node supprime aussi toutes ses connexions.

    Annuler la dernière action

    • PC : Ctrl+Z (Windows/Linux) ou Cmd+Z (Mac), ou bouton ↩ dans le header.
    • Smartphone : Bouton ↩ dans la barre du bas.
    • L'historique conserve les 30 dernières actions (ajout node, suppression node, ajout fil, suppression fil).

    Effacer tout le canvas

    • PC : Bouton 🗑 dans le header → confirmation requise.
    • Smartphone : ••• Plus → 🗑 Effacer le canvas → confirmation requise.

    Panneau Propriétés

    Affiche les informations de l'élément sélectionné :

    • Nom et catégorie
    • Tags (type, technologie, usage)
    • Description technique
    • Caractéristiques : fréquence, phantom 48V requis/non requis
    • Ports : liste de tous les ports avec direction (▶ sortie / ◀ entrée) et type de connecteur
    • ⚠ Avertissements AV : phantom sur ruban, instrument sans DI, etc.
    • Prérequis : câbles, alimentations, accessoires nécessaires
    • Connexions actives : liste des fils reliés à cet élément avec le type de câble et l'équipement cible

    Modifier un élément

    • PC : Sélectionner un node → cliquer ✏ Modifier en haut du panneau droit → modifier nom, description, prérequis.
    • Smartphone : Appuyer sur ⚙ Infos dans la barre du bas après sélection → les infos s'affichent dans le panel. Pas d'édition directe sur mobile.

    Accès sur smartphone

    • Appuyer sur ⚙ Infos dans la barre du bas pour ouvrir le panneau propriétés.
    • Ou sélectionner un node → le panel s'ouvre automatiquement.

    Presets et sauvegarde

    Sauvegarde automatique

    Tout le synoptique (nodes et connexions) est sauvegardé automatiquement dans le localStorage du navigateur à chaque modification. Il se recharge à l'ouverture.

    ⚠ La sauvegarde est locale au navigateur. Vider le cache = perdre les données. Utiliser l'export JSON pour une sauvegarde externe.

    Presets nommés

    • PC : Bouton 💾 Preset dans le header → saisir un nom → le preset s'ajoute dans la liste en bas du panneau droit.
    • Smartphone : ••• Plus → 💾 Sauvegarder un preset → saisir un nom.
    • Cliquer sur un preset pour le charger (remplace le canvas actuel).
    • Cliquer sur ✕ à droite d'un preset pour le supprimer.
    • Les presets sont persistants entre sessions (localStorage).

    Export et impression

    Export JSON

    Exporte le synoptique complet (nodes + connexions + positions) en fichier .json.

    • PC : Bouton ⬇ JSON dans le header.
    • Smartphone : ••• Plus → ⬇ Exporter JSON.
    Le fichier JSON peut être partagé ou archivé. L'import JSON n'est pas encore disponible dans cette version.

    Impression / PDF

    • PC : Bouton 🖨 dans le header → dialogue impression du navigateur. Choisir "Enregistrer en PDF" pour un export PDF propre.
    • Smartphone : ••• Plus → 🖨 Imprimer / PDF → utiliser le partage iOS/Android pour "Imprimer" ou "Enregistrer en PDF".
    • Lors de l'impression : header, panneaux latéraux, légende et barre du bas sont masqués. Le canvas s'affiche sur fond blanc.

    Thème et affichage

    • Thème clair : activé par défaut.
    • Thème sombre : bouton ☀/🌙 dans le header (PC) ou ••• Plus → 🌗 Changer le thème (smartphone).
    • Le thème est mémorisé entre les sessions.

    Légende des câbles

    Affichée en bas à gauche du canvas. Cliquer sur 🗺 dans le header pour l'afficher/masquer.

    Avertissements AV automatiques

    L'application détecte et signale automatiquement les situations dangereuses ou sous-optimales :

    🔴 Micro ruban + console

    Déclencheur : Un micro ruban (Royer R-121, Beyerdynamic M160) est connecté à une table de mixage.

    Message : "Vérifiez que le Phantom 48V est OFF sur cette voie — un ruban s'y détruit !"

    Action : Désactiver le phantom 48V sur la voie concernée avant d'allumer le micro.

    ⚠ Instrument Jack → console directement

    Déclencheur : Une guitare, basse ou clavier est connecté directement à une entrée XLR de console.

    Message : "Jack instrument → console directement : risque de bruit de masse. Utilisez une DI."

    Action : Insérer une boîte DI active (ex: Radial J48) entre l'instrument et la console.

    Les avertissements apparaissent :

    • Sur le node concerné (bandeau coloré sous les ports)
    • Dans le panneau Propriétés
    • Sous forme de toast au moment de la connexion

    Hébergement et déploiement

    SynOptic AV Pro v3 est un fichier HTML unique autonome. Aucun serveur, aucune base de données.

    Option 1 — Netlify Drop (le plus simple, gratuit)

  • Aller sur app.netlify.com/drop
  • Glisser le fichier index.html
  • URL publique instantanée (ex: amazing-name-123.netlify.app)
  • Pour une URL fixe : créer un compte Netlify gratuit

    • Option 2 — GitHub Pages (gratuit, version contrôlée)

  • Créer un repository GitHub
  • Uploader index.html
  • Settings → Pages → Branch: main → Save
  • URL : tonpseudo.github.io/synoptic-av

    • Option 3 — Vercel (gratuit, déploiement automatique)

  • Connecter le repository GitHub à Vercel
  • Déploiement automatique à chaque push

    • Domaine personnalisé

    Toutes les options ci-dessus acceptent un domaine custom (ex: synoptic.monsite.fr) acheté sur OVH ou Namecheap (~10€/an).
